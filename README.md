# ModelingIndividualAnnotators
Code implementation for the paper The Whole Is Bigger Than the Sum of Its Parts: Modeling Individual Annotators to Capture Emotional Variability

We recommend [using the code](https://github.com/chailab-umich/MoreSimilarThanDissimilar) from our newer paper, More Similar than Dissimilar: Modeling Annotators for Cross-Corpus Speech Emotion Recognition published at ASRU 2025.
